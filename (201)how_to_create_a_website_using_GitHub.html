はじめに

「GitHub」という「無料のHP公開サービス」に、html等のデータを転送して、閲覧可能な状態を構築します。html、css、jpg等ファイルを公開できます。変更したファイルだけ更新できます。

第１章　GitHubに新しく登録する方法（GitHubアカウント作成）

(1) Sign up

  1. ブラウザで、https://github.comを開く
  2. 右上にある「sign up（最初の場合）、sign in（登録済みの場合）」をクリックす

(2) アカウントを作成する

入力画面

  1. 「e-mail address」→「continue」
  2. 「password」→「continue」
  3. 「username」：ABC、公開URL「https://ABC.github.io/〇〇〇〇/」となる。→「continue」
  4. メール確認：(a)メール内に「verify email address」があれば、クリックして完了
    (b)メール内に「vertification code」があれば、6桁数字を入力画面の枠に入力して → 「完了?」

(3) ログインする

「https://github.com」に入る

  1. 右上の「sign in」をクリックする
  2. email（またはusername）、passwordを入力する

(4) Home画面で「Repository」（保管庫）を作る

初めての場合

  1. 「create repository」か「start a project」が表示される
  2. 右上の「 + 」をクリックする
  3. 「New repository」を選択する
  4. 「repository name」を決める
  5. 「poblic」を選択する
  6. 「create repository」をクリックする

    7. 「Home画面」にrepositoryが作成されているので、次回からは、その名前のrepositoryを選びます。

第２章　初めてHPを公開する方法

(1) HPのhtml、css、jpgなどを準備する

Macに「HP用のフォルダ」を作り、「index.html、style.css、101.html、102.html、jpg」などを入れておきます。
（注意）トップページは必ず「index.html」という名前にすること。

(2) ファイルをアップロード

「リポジトリ画面」で

  1. 右上の「add file」を押し、「upload files」を開く
  2. Mac内の「HP用フォルダ」から、全部のファイルをドラッグ＆ドロップする
  3. 「commit changes」を押す

(3) GitHub pagesを有効にする

新しくリポジトリを作製した場合には必須！

  1. 作製したリポジトリを開く（その名前のところをクリックする）
  2. 上の方に、「code、issues、pull requests、action、---- settings」が並んでいるので、「settings」をクリックする
  3. 左側の「pages」のsettingsを開くと、「general、access、code and automation、--- pages」が並んでいるので、「pages」をクリックする
  4. 「Build and development」という見出しがあり、その中に「source」がある。「Deploy from a branch」を選択する。
    （意味は、「Branchの内容をホームページとして公開する」ということです）
  5. 下に「Branch」という項目が出るので、「main」を選びます。
    （意味は、「mainという保存場所を公開します」ということです）
  6. その右側に「/(root)」があります。
    （意味は、「リボジトリの一番上のフォルダを公開する」ということです）
    「(root)」を選びます。
  7. 最後に、「save」を押します（これで公開されます！）
  8. saveを押した後、数十秒すると、画面に「Your site is live at https://----」と表示されます。
    これで、HPは公開されました

第３章　表示の確認

MacやiPhoneで、HPを確認する。
リンク、画像、メニューなどを確認する。

「ブックマーク」や「お気に入り」登録

Macでは、最初の画面を「ブックマーク」しておくこと
iPhoneでは、「お気に入り」登録しておくこと

第４章　HPを更新する方法

htmlを修正したら、htmlファイルだけを、cssを修正したら、style.cssだけを、画像を修正したら、jpgだけを、新しいhtmlページを作製したら、そのhtmlだけを、追加します。

(1) 変更方法

  1. 「repository」画面を開き、右上の「add file」を押し、「upload files」を開く
  2. 修正したファイルだけをドラッグする
  3. 「commit changes」をクリックする
  4. １から２分待つと、ブラウザで更新を確認できる

(2) ファイルを削除する方法

ファイル名を修正して新たにアップロードした場合など、古い名称のファイルが残る場合があります。
そのような場合の不要なファイルを削除する方法を示します。

  1. 不要なファイルをクリックすると、新しいページ（編集ページ）に移る
  2. 右上の「・・・」三点メニューをクリックする
  3. 一番下の「Delete file]」をクリックする
  4. 画面下に出る「Commit changes」をクリックすると、数十秒後に削除される

メモ

・ 無料で利用可能であり、容量は1GB程度。
・ Html、css、javaScriptをそのまま公開できる。
・ GitHubがバックアップの役割も果たしてくれる。
